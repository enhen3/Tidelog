# TideLog 1.1.49

## Seven-Day Full-Product Trial

- New users now see the seven-day trial clearly during first-run onboarding.
- The trial starts only after the user configures AI and explicitly chooses to begin it; installing the plugin or reading onboarding does not start the clock.
- No payment method is required, and the trial does not renew automatically.
- During the trial, users can experience complete reviews, weekly and monthly reports, and profile updates before deciding whether to purchase Pro.

## Value-First Pro Experience

- Upgrade prompts now explain the personal value already unlocked instead of only listing gated features.
- Trial, expired-trial, inactive-license, and paid states each have clearer next steps.
- The first profile generated from existing journals remains a free one-time experience; later profile updates follow the trial or Pro path.

## Review And Insight Reliability

- Improved full Review completion and follow-up suggestions across daily, weekly, and monthly views.
- Fixed loop detection so existing records are recognized more consistently.
- Improved profile update handling and insight actions after Review.
- Added regression coverage for trial eligibility, activation timing, expiration, onboarding copy, paid-license compatibility, Review actions, and profile updates.
