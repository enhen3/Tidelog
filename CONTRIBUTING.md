# Contributing to TideLog

Thanks for helping improve TideLog. This repository is source-available for review, issue reports, and upstream pull requests.

## Report bugs

Open a GitHub issue with:

- TideLog version and Obsidian version.
- Desktop or mobile platform.
- Steps to reproduce.
- Expected behavior and actual behavior.
- Screenshots or console errors when useful.

Do not post API keys, full license keys, private journal content, or purchase details in public issues.

## Pull requests

Before opening a pull request:

1. Keep the change focused on one bug or feature.
2. Run `npm run check`.
3. If you changed the license API, also run `npm run typecheck:api`.
4. Update `README.md` or `PRIVACY.md` when behavior, network use, or data access changes.

TideLog is not open source software. Contributions are accepted only for inclusion in the upstream TideLog project under the repository license.
