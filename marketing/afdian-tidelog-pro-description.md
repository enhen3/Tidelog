## 页面标题建议

TideLog Pro｜把 Obsidian Daily Note 变成长期反馈系统

## 一句话副标题

不是多写一点笔记，而是让每天的计划、复盘和洞察真正回到下一步行动。

## 首屏说明

TideLog 是一个 Obsidian 插件，用来连接新版的三个核心入口：

- Plan：日 / 周 / 月任务与灵感收集
- Review：当月闭环、今日复盘和历史补复盘
- Insights：本周报告 / 本月报告 / AI 眼中的你

如果你已经在 Obsidian 里写 Daily Notes，但经常感觉“记录很多，行动没有改变”，TideLog Pro 就是为这个问题设计的。

它不会把你的日常记录搬到另一个 SaaS。你的笔记默认仍然留在自己的 Obsidian vault 里，TideLog 只是把它们组织成一个可以持续回看的反馈闭环。

```text
Plan → Review → Insights → Action
```

## 你购买的是什么

购买 TideLog Pro 后，你会获得一个 License Key，可在：

Obsidian Settings → TideLog → Pro

中输入并激活。

每个 License 支持最多 3 台设备激活。

## 版本价格

- 年度版：早期支持价 ¥39 / 年（原价 ¥49）
- 终身版：早期支持价 ¥78 一次性买断（原价 ¥99）

如果你只是想体验基础计划、任务记录和前两个 Review 问题，可以先使用免费版。

如果你希望长期追踪自己的行动模式、复盘质量和周/月变化，建议购买 Pro。

## Pro 解锁内容

### 1. 完整 Review 问题流

免费版适合跑通基本记录；Pro 解锁更完整的 Review 问题流，帮助你从“今天发生了什么”进一步进入：

- 目标是否对齐
- 哪些行为有效
- 哪些困难重复出现
- 情绪和能量如何变化
- 明天最应该调整什么

### 2. Insights：周报、月报和 AI 画像

基于你的 Markdown 笔记生成长期洞察，包括：

- 本周 / 本月反复出现的行为模式
- 成功经验和有效策略
- 卡点、焦虑、拖延和注意力模式
- 可以沉淀下来的个人原则
- 下一阶段行动建议
- 「AI 眼中的你」画像更新

周报至少需要 3 次完整闭环，月报至少需要 8 次完整闭环；已有报告会先在 Insights 当前页展示简要预览。如果之后新增计划或复盘记录，可以用新记录更新本周期报告。AI 功能使用你自己配置的 AI 服务商和 API Key。TideLog 不内置偷偷调用的模型额度。

### 3. Plan / Review / Insights

Pro 会把你的计划、复盘、任务和长期模式放到更容易回看的位置：

- Plan：默认突出今天 To Do，支持日 / 周 / 月和灵感收集
- Review：用蓝色计划半环 + 金色复盘半环显示本月闭环，并支持补做历史复盘
- Insights：预览、生成或更新本周报告、本月报告和 AI 画像

## 适合谁

TideLog Pro 适合：

- 每天写 Obsidian Daily Notes，但希望记录能影响行动的人
- 独立开发者、自由职业者、学生、研究者、转型期个体
- 正在搭建第二大脑、个人操作系统、复盘系统的人
- 希望用 AI 理解自己，但不想把私人笔记搬到另一个平台的人
- 愿意用 3–5 分钟完成 Plan + Review，换取长期自我校正的人

如果你只是偶尔写漂亮日记，或者不需要复盘、周报和行动闭环，免费版可能已经足够。

## 隐私与数据

TideLog 的基本原则是：你的日常记录默认留在自己的 vault 里。

- AI API Key 和 Pro License Key 使用 Obsidian SecretStorage 保存。
- TideLog 不包含客户端遥测、分析 SDK、动态广告或自动更新机制。
- 只有当你主动对话、生成/更新报告、测试连接、完成复盘后刷新计划建议、激活 License 或打开购买 / License portal 时，才会发起网络请求。
- AI 功能会把必要提示词和相关笔记内容发送给你自己配置的 AI 服务商。

## 购买后怎么用

1. 在 Obsidian Community Plugins 搜索并安装 `TideLog`。
2. 打开 Obsidian Settings → TideLog。
3. 在 Pro 区域输入购买后获得的 License Key。
4. 第一次使用建议先跑：
   - 在 Plan 写下今天的一项任务
   - 在 Review 完成一次当天复盘
5. 不需要一开始研究所有设置。先跑通 Plan → Review → Insights，再慢慢查看或更新周报、月报和 AI 画像。

## 常见问题

### 年度版和终身版有什么区别？

两者解锁的 TideLog Pro 功能相同。年度版有效期一年，适合先完整使用一年；终身版一次买断，购买后长期使用。

这里使用“年度版 / 终身版”作为购买选项名称；购买后获得的仍然是 TideLog Pro License，用于在插件内激活和管理设备。

### 一份 License 可以用几台设备？

每个 TideLog Pro License 支持最多 3 台设备。换机或设备数量达到上限时，可以通过 License Portal 管理已激活设备。

### 我不会配置 AI，可以用吗？

可以。你可以先使用不依赖 AI 的基础计划与复盘功能。AI 周报、月报和聊天类功能需要你自己配置 AI Provider 和 API Key。

### 购买后没有收到 License Key 怎么办？

请先检查爱发电订单消息。如果仍然找不到，可以通过 TideLog 的 License Portal 或 GitHub Issues 联系我。请不要在公开 issue 中粘贴 License Key、API Key 或私人笔记内容。

### 我可以先免费试用吗？

可以。TideLog 可以直接从 Obsidian Community Plugins 安装。免费版足够你先判断自己是否喜欢这个工作流。
