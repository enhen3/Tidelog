## 页面标题建议

TideLog Pro｜把 Obsidian Daily Note 变成长期反馈系统

## 一句话副标题

不是多写一点笔记，而是让每天的计划、复盘和洞察真正回到下一步行动。

## 首屏说明

TideLog 是一个 Obsidian 插件，用来连接：

- 晨间计划
- 晚间复盘
- AI 周报 / 月报洞察
- Dashboard / Calendar / Kanban 行动视图

如果你已经在 Obsidian 里写 Daily Notes，但经常感觉“记录很多，行动没有改变”，TideLog Pro 就是为这个问题设计的。

它不会把你的日常记录搬到另一个 SaaS。你的笔记默认仍然留在自己的 Obsidian vault 里，TideLog 只是把它们组织成一个可以持续回看的反馈闭环。

```text
Plan → Review → Insight → Action
```

## 你购买的是什么

购买 TideLog Pro 后，你会获得一个 License Key，可在：

Obsidian Settings → TideLog → Pro

中输入并激活。

每个 License 支持最多 3 台设备激活。

## 版本价格

- 年度版：¥49 / 年
- 终身版：¥99 一次性买断

如果你只是想体验基础晨间计划和基础记录，可以先使用免费版。

如果你希望长期追踪自己的行动模式、复盘质量和周/月变化，建议购买 Pro。

## Pro 解锁内容

### 1. 完整晚间复盘流程

免费版适合跑通基本记录；Pro 解锁更完整的 5+4 复盘结构，帮助你从“今天发生了什么”进一步进入：

- 目标是否对齐
- 哪些行为有效
- 哪些困难重复出现
- 情绪和能量如何变化
- 明天最应该调整什么

### 2. AI 周报与月报洞察

基于你的 Markdown 笔记生成长期洞察，包括：

- 本周 / 本月反复出现的行为模式
- 成功经验和有效策略
- 卡点、焦虑、拖延和注意力模式
- 可以沉淀下来的个人原则
- 下一阶段行动建议

AI 功能使用你自己配置的 AI 服务商和 API Key。TideLog 不内置偷偷调用的模型额度。

### 3. Dashboard / Calendar / Kanban

Pro 会把你的计划、复盘、任务和长期模式放到更容易回看的位置：

- Dashboard：看今天、这周和关键模式
- Calendar Heatmap：看情绪和记录连续性
- Kanban：把复盘后的行动带回执行层

## 适合谁

TideLog Pro 适合：

- 每天写 Obsidian Daily Notes，但希望记录能影响行动的人
- 独立开发者、自由职业者、学生、研究者、转型期个体
- 正在搭建第二大脑、个人操作系统、复盘系统的人
- 希望用 AI 理解自己，但不想把私人笔记搬到另一个平台的人
- 愿意用 3–5 分钟晨间计划 + 晚间复盘，换取长期自我校正的人

如果你只是偶尔写漂亮日记，或者不需要复盘、周报和行动闭环，免费版可能已经足够。

## 隐私与数据

TideLog 的基本原则是：你的日常记录默认留在自己的 vault 里。

- AI API Key 和 Pro License Key 使用 Obsidian SecretStorage 保存。
- TideLog 不包含客户端遥测、分析 SDK、动态广告或自动更新机制。
- 只有当你主动使用 AI、测试连接、激活 License 或打开购买 / License portal 时，才会发起网络请求。
- AI 功能会把必要提示词和相关笔记内容发送给你自己配置的 AI 服务商。

## 购买后怎么用

1. 在 Obsidian Community Plugins 搜索并安装 `TideLog`。
2. 打开 Obsidian Settings → TideLog。
3. 在 Pro 区域输入购买后获得的 License Key。
4. 第一次使用建议先跑：
   - TideLog: Start morning review
   - TideLog: Start evening review
5. 不需要一开始研究所有设置。先跑通一天，再慢慢打开 Dashboard、Calendar 和 Weekly Insight。

## 常见问题

### 我不会配置 AI，可以用吗？

可以。你可以先使用不依赖 AI 的基础计划与复盘功能。AI 周报、月报和聊天类功能需要你自己配置 AI Provider 和 API Key。

### 购买后没有收到 License Key 怎么办？

请先检查爱发电订单消息。如果仍然找不到，可以通过 TideLog 的 License Portal 或 GitHub Issues 联系我。请不要在公开 issue 中粘贴 License Key、API Key 或私人笔记内容。

### 我可以先免费试用吗？

可以。TideLog 可以直接从 Obsidian Community Plugins 安装。免费版足够你先判断自己是否喜欢这个工作流。
