## 页面标题建议

TideLog Pro｜把 Obsidian Daily Note 变成长期反馈系统

## 一句话副标题

不是多写一点笔记，而是让每天的计划、复盘和洞察真正回到下一步行动。

## 首屏说明

TideLog 是一个 Obsidian 插件，用来连接新版的三个核心入口：

- Plan：日 / 周 / 月任务与灵感收集
- Review：当月闭环、今日复盘和历史补复盘
- Insights：本周报告 / 本月报告 / AI 眼中的你

如果你已经在 Obsidian 里写 Daily Notes，但经常感觉“记录很多，行动没有改变”，TideLog Pro 就是为这个问题设计的。

它不会把你的日常记录搬到另一个 SaaS。你的笔记默认仍然留在自己的 Obsidian vault 里，TideLog 只是把它们组织成一个可以持续回看的反馈闭环。所有 AI 功能由 TideLog 内置服务提供，装上即用，无需申请或配置任何 API Key。

```text
Plan -> Review -> Insights -> Action
```

## 你购买的是什么

购买 TideLog Pro 后，你会获得一个 License Key，可在：

Obsidian Settings -> TideLog -> Pro

中输入并激活。

TideLog Pro 是时长制订阅：月订阅的有效期是 1 个月，年订阅的有效期是 12 个月。到期后自动降级为免费档，不会产生任何扣款；插件内会在临近到期时提醒你续费。

每个 License 支持最多 3 台设备激活。

## 版本价格

- 月订阅：¥19 / 月
- 年订阅：¥148 / 年（折合月付约 6.5 折）

两种订阅解锁的功能完全相同，区别只在有效期和价格。

- 不会自动续费：爱发电平台层面不支持任何形式的自动扣费，TideLog Pro 不会、也无法自动扣款。你购买的是一段固定时长，到期后自动降级为免费档。
- 到期不影响数据：你的所有笔记和已生成的报告都留在本地 vault 里，不会丢失。
- 可以先试用：插件内提供 7 天全功能试用，无需绑定支付方式，由你主动开启，到期自动结束，不会转成付费。
- 不付费也能长期用：计划与复盘的本地功能永久免费，每月另赠 3 次「今日洞察」。

如果你希望长期追踪自己的行动模式、复盘质量和周/月变化，建议选择年订阅；如果只想先按月使用一段时间，月订阅更灵活。

## Pro 解锁内容

Pro 在有效期内的核心配额：

- 周报 / 月报 / 画像：不限次生成与更新
- AI 对话：每月 200 次

所有 AI 功能由 TideLog 内置服务提供，无需申请或配置任何 API Key。

### 1. 完整 Review 问题流

免费版适合跑通基本记录；Pro 解锁更完整的 Review 问题流，帮助你从“今天发生了什么”进一步进入：

- 目标是否对齐
- 哪些行为有效
- 哪些困难重复出现
- 情绪和能量如何变化
- 明天最应该调整什么

### 2. Insights：周报、月报和 AI 画像

基于你的 Markdown 笔记生成长期洞察，包括：

- 本周 / 本月反复出现的行为模式
- 成功经验和有效策略
- 卡点、焦虑、拖延和注意力模式
- 可以沉淀下来的个人原则
- 下一阶段行动建议
- 「AI 眼中的你」画像更新

周报至少需要 3 次完整闭环，月报至少需要 8 次完整闭环；已有报告会先在 Insights 当前页展示简要预览。如果之后新增计划或复盘记录，可以用新记录更新本周期报告。周报、月报和画像在 Pro 有效期内不限次。

### 3. AI 对话

Pro 有效期内，AI 对话每月可用 200 次。与报告类功能一样，由 TideLog 内置 AI 服务提供，同样无需配置任何 API Key。

### 4. Plan / Review / Insights

Pro 会把你的计划、复盘、任务和长期模式放到更容易回看的位置：

- Plan：默认突出今天 To Do，支持日 / 周 / 月和灵感收集
- Review：用蓝色计划半环 + 金色复盘半环显示本月闭环，并支持补做历史复盘
- Insights：预览、生成或更新本周报告、本月报告和 AI 画像

## 适合谁

TideLog Pro 适合：

- 每天写 Obsidian Daily Notes，但希望记录能影响行动的人
- 独立开发者、自由职业者、学生、研究者、转型期个体
- 正在搭建第二大脑、个人操作系统、复盘系统的人
- 希望用 AI 理解自己，但不想把私人笔记搬到另一个平台的人
- 愿意用 3–5 分钟完成 Plan + Review，换取长期自我校正的人

如果你只是偶尔写漂亮日记，或者不需要复盘、周报和行动闭环，免费版可能已经足够。

## 隐私与数据

TideLog 的基本原则是：你的日常记录默认留在自己的 vault 里。

- 计划、任务和复盘都以 Markdown 写入你的 vault，本地功能不依赖 TideLog 服务端。
- AI 只在你主动触发时调用：对话、生成或更新报告、生成今日洞察，或完成复盘后刷新计划建议。
- 使用 AI 时，只会把该次生成所必需的提示词和相关笔记片段发送到 TideLog 服务端，由服务端转发给大模型服务商；服务端不存储笔记正文与 AI 响应正文。
- Pro License Key 使用 Obsidian SecretStorage 保存；使用 AI 无需你提供任何 API Key。
- 已激活 Pro 时，插件会在 Obsidian 启动时后台校验一次 License，只发送 License Key 和一个生成的设备标识；未激活 License 时，启动不产生任何网络请求。
- TideLog 不包含客户端遥测、分析 SDK、动态广告或自动更新机制。

## 购买后怎么用

1. 在 Obsidian Community Plugins 搜索并安装 `TideLog`。
2. 装上即用：AI 功能由 TideLog 内置服务提供，无需申请或配置任何 API Key。可以先开启 7 天全功能试用完整跑一个周期，无需绑定支付方式。
3. 决定付费后，打开 Obsidian Settings -> TideLog，在 Pro 区域输入购买获得的 License Key。
4. 第一次使用建议先跑：
   - 在 Plan 写下今天的一项任务
   - 在 Review 完成一次当天复盘
5. 不需要一开始研究所有设置。先跑通 Plan -> Review -> Insights，再慢慢查看或更新周报、月报和 AI 画像。

## 常见问题

### 月订阅和年订阅有什么区别？

解锁的功能完全相同，区别只在有效期和价格：月订阅 ¥19，有效期 1 个月；年订阅 ¥148，有效期 12 个月，折合月付约 6.5 折。两种都是一次性购买一段固定时长，都不会自动续费。

### 到期后会怎样？

到期后自动降级为免费档，不会产生任何扣款。你的所有笔记、任务和已生成的报告都留在本地 vault 里，不会丢失，也不会被删除。想继续使用 Pro 功能时，再购买一段时长即可；插件内会在到期前提醒你。

### 为什么不能自动续费？

如实说明：爱发电平台层面不支持任何形式的自动扣费，TideLog 无法在平台上开启自动续费。所以 Pro 采用时长制，你买到的是一段固定时长，到期自动降级为免费档。好处是不存在“忘了取消订阅被扣款”的情况，续不续费始终由你决定。

### 一份 License 可以用几台设备？

每个 TideLog Pro License 支持最多 3 台设备。换机或设备数量达到上限时，可以通过 License Portal 管理已激活设备。

### 需要自己准备 API Key 吗？

不需要。AI 功能由 TideLog 内置服务提供，装上即用，不用申请 API Key，也不用选择大模型服务商。

### 免费档能用什么？

计划与复盘的本地功能永久免费：日 / 周 / 月任务、灵感收集、基础 Review 问题流（前 2 个已启用问题）和历史补复盘都可以长期使用，每月另赠 3 次「今日洞察」。Pro 解锁完整 Review 问题流、不限次的周报 / 月报 / 画像和每月 200 次 AI 对话。

### 购买后没有收到 License Key 怎么办？

请先检查爱发电订单消息。如果仍然找不到，可以通过 TideLog 的 License Portal 或 GitHub Issues 联系我。请不要在公开 issue 中粘贴 License Key 或私人笔记内容。

### 我可以先免费试用吗？

可以。安装后即可在插件内开启 7 天全功能试用：完整复盘、周报、月报和「AI 眼中的你」全部可用。无需绑定支付方式，由你主动开启，不会自动续费；试用结束后，已有记录和报告仍留在本地。
