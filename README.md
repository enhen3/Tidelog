# TideLog

> 把每日计划、晚间复盘和 AI 洞察，沉淀成 Obsidian 里的个人成长系统。

大多数日记只负责记录：今天发生了什么、我想到了什么、我完成了什么。
**TideLog 想解决的是下一步：如何让这些记录持续反馈到你的行动、判断和自我理解。**

它把 Obsidian 里的日常写作组织成一条清晰的闭环：

```text
晨间计划 → 当日记录 → 晚间复盘 → 周/月洞察 → 更好的下一步行动
   ↑                                                   ↓
   └────────────────── 持续变清醒的反馈循环 ──────────────┘
```

如果你已经在 Obsidian 里写 Daily note，却经常觉得「写了很多，但没有真正被自己用起来」，TideLog 就是为这种场景设计的。

## TideLog 能帮你做什么

- **早上更快进入状态**：用晨间 SOP 梳理精力、优先级、今日任务和未完成事项。
- **晚上不再面对空白页**：用可自定义的复盘问题，引导你回看目标、成果、情绪、焦虑和明天最重要的一步。
- **从日记里看见模式**：用周报、月报、情绪趋势、原则提取和行为模式，发现自己反复出现的问题与优势。
- **把复盘变成行动系统**：未完成任务会自动继承，今日计划、晚间复盘和洞察报告都落回你的 Markdown 笔记。
- **保留 Obsidian 的数据主权**：TideLog 写入你自己的 Vault；只有在你主动使用 AI 或激活 Pro 时才会发起网络请求。

## 适合谁

TideLog 尤其适合这些 Obsidian 用户：

- 已经写日记、Daily note 或周期复盘，但希望它们产生更稳定的行动反馈。
- 想用 AI 做长期自我观察，而不是只进行一次性的聊天。
- 希望把任务、情绪、原则、模式和人生复盘沉淀在自己的 Markdown Vault 里。
- 正在搭建个人成长系统、第二大脑、复盘系统或独立工作流。

TideLog 不追求把你的 Vault 变复杂。它更像一套固定的日常仪式：每天帮你问对问题，并把答案沉淀成可回看的结构。

## 核心工作流

### 1. 晨间计划：把一天从混乱变成清晰

- 评估今日精力状态。
- 输入多个任务，并支持子任务结构。
- 自动继承过去 3 天未完成任务。
- 写入 Daily note 的 `## Morning Plan` 区域。

### 2. 晚间复盘：用问题替代空白页

免费版可以完成前 2 个复盘问题；Pro 解锁完整的 5 个必答问题 + 4 个可选深度问题。

**必答问题：**

1. 目标对齐：今天计划里的事情推进得怎么样？
2. 成功日记：今天有哪些值得记录的成果？
3. 情绪记录：今天哪些时刻让你开心？整体情绪分数是多少？
4. 焦虑觉察：今天有哪些负面情绪或压力？它们来自哪里？
5. 明日计划：明天最重要的一件事是什么？

**可选深度问题：**

6. 深度分析：用 5 Whys 追问问题根因。
7. 哲学复盘：用斯多葛三问校准行动。
8. 原则提取：把经历沉淀成可复用原则。
9. 自由书写：保留开放表达空间。

你可以在设置页里调整问题顺序、修改问题内容、启用或关闭某些问题。

### 3. 洞察系统：让日记开始反过来理解你

- 周报洞察：任务完成率、情绪趋势、成功模式、挑战分析。
- 月报洞察：月度趋势、成长里程碑、长期模式。
- 用户画像建议：AI 基于你的复盘内容，建议更新自我认知画像。
- 原则与模式沉淀：把反复出现的判断、行为和经验整理出来。

### 4. 可视化视图：把个人状态看见

- 日历热力图：按日期查看情绪与复盘记录。
- Kanban 金字塔：用月 / 周 / 日层级查看计划和任务。
- Dashboard：今日聚焦、周进度、情绪趋势、随机原则和活跃模式。

### 5. 自由对话：在自己的上下文里和 AI 讨论

- 随时打开 TideLog Chat。
- 使用你配置的 AI 服务商和 API Key。
- 支持对计划、复盘、想法和行动进行教练式对话。

## 快速开始

1. 在 Obsidian Community plugins 中安装 TideLog。
2. 打开 **Obsidian 设置 → TideLog**。
3. 配置你偏好的 AI 服务商和 API Key，并点击 **Test connection**。
4. 运行 `TideLog: Start morning review` 开始晨间计划。
5. 运行 `TideLog: Start evening review` 完成晚间复盘。
6. 如果你需要完整复盘流程、仪表盘、日历热力图和 AI 周/月洞察，可以升级 TideLog Pro。

## 文件结构

TideLog 只会在你使用相关功能时创建或更新文件。默认结构示例：

```text
your-vault/
├── 01-Daily/
│   ├── 2026-03-06.md
│   └── ...
├── 02-Plan/
│   ├── Weekly/
│   │   └── 2026-W10.md
│   └── Monthly/
│       └── 2026-03.md
└── 03-Archive/
    ├── user_profile.md
    ├── principles.md
    ├── patterns.md
    ├── quick_capture.md
    └── Insights/
        ├── 2026-W10-weekly.md
        └── 2026-03-monthly.md
```

所有路径都可以在设置中调整。

## 数据、隐私与网络请求

TideLog 在你的 Obsidian Vault 内运行，需要以下权限来完成核心工作流：

- **Vault 枚举**：扫描你配置的日记、复盘和洞察文件夹，用于日历热力图、Dashboard、Kanban、任务继承和周/月总结。
- **Vault 读取**：读取你选择的笔记或 TideLog 配置文件夹中的笔记，用于渲染视图、继承未完成任务，或生成你主动触发的 AI 提示词。
- **Vault 写入**：在你配置的文件夹中创建或更新晨间计划、晚间复盘、任务、洞察报告、模板和缓存文件。
- **网络访问**：仅在你使用 AI 功能时请求你配置的 AI 服务商；仅在激活或验证 Pro 时请求 TideLog 授权服务。

TideLog 只在以下场景发起 HTTPS 请求：

1. **AI API calls**：使用晨间计划、晚间复盘、洞察生成或自由对话等 AI 功能时，会将相关提示词和必要笔记内容发送到你在设置中配置的 AI 服务商。
2. **Connection tests**：点击测试连接按钮时，会向所选 AI 服务商验证 API Key 和模型配置。
3. **License activation and verification**：激活 Pro 后，会向 `https://tidelog-api.mydreamchronicle.com` 发送 License key 和生成的设备标识符，用于验证授权和管理 3 台设备限制。授权请求不包含 Vault 笔记内容。
4. **Purchase and License portal links**：设置页按钮会在浏览器中打开爱发电或 `https://tidelog-api.mydreamchronicle.com/portal`，此操作由用户主动触发。

TideLog 不包含客户端遥测、分析 SDK、动态广告或自动更新机制。TideLog 不访问 Obsidian Vault 之外的文件。完整隐私说明见 [PRIVACY.md](./PRIVACY.md)。

## 安装与开发

### 手动安装

1. 从最新 [Release](https://github.com/enhen3/Tidelog/releases) 下载 `main.js`、`manifest.json`、`styles.css`。
2. 在你的 Vault 中创建 `.obsidian/plugins/tidelog/`。
3. 将三个文件复制到该目录。
4. 重启 Obsidian → Settings → Community Plugins → Enable **TideLog**。

### 本地开发

```bash
git clone https://github.com/enhen3/Tidelog.git
cd Tidelog
npm install
npm run dev           # Development mode (watch)
npm run build         # Production build only
npm run deploy        # Copy built assets to your local vault
npm run check         # Typecheck, lint, tests, build, release asset checks
```

`npm run deploy` requires `OBSIDIAN_VAULT` to point at your test vault path.

# TideLog

> Turn daily planning, evening review, and AI insights into a durable personal growth system inside Obsidian.

Most journals help you record what happened. TideLog is designed for the next step: turning those records into better decisions, clearer priorities, and visible personal patterns.

TideLog helps you run a repeatable **Plan → Log → Review → Insight** loop without leaving your vault.

## What TideLog does

- **Plan the day** with a morning SOP that captures energy, priorities, tasks, subtasks, and carry-forward items.
- **Review the day** with customizable evening questions instead of staring at a blank page.
- **Find patterns** with weekly/monthly insight reports, emotion trends, principles, and recurring behaviors.
- **Turn reflection into action** with task carry-forward, dashboards, calendar heatmaps, and AI-guided insight dialogues.
- **Keep ownership of your vault**: TideLog writes Markdown files to your Obsidian folders and only calls external services when you trigger AI or license features.

## Free vs Pro

The free version is enough to try the workflow. Pro is designed for users who want TideLog to become their long-term self-review system.

- **Free**: morning planning, free chat with your configured AI provider, basic daily note writing, first 2 evening review questions.
- **Pro**: full 5+4 evening review, weekly/monthly insight reports, dashboard, calendar heatmap, profile suggestions, and pattern/principle extraction.
- **Buy Pro**: <https://afdian.com/item/463307362c2f11f1b39d52540025c377>

## Quick start

1. Install TideLog from Obsidian Community plugins.
2. Open **Obsidian Settings → TideLog**.
3. Configure your preferred AI provider and run **Test connection**.
4. Use `TideLog: Start morning review` to plan your day.
5. Use `TideLog: Start evening review` to complete your daily reflection.
6. Upgrade to **TideLog Pro** when you want the full review flow, dashboards, calendar heatmap, and AI insight reports.

## Network usage

TideLog makes outbound HTTPS requests only when you configure or trigger features that need them:

1. **AI API calls** — TideLog sends the relevant prompt and selected journal content to the AI provider configured in settings.
2. **Connection tests** — TideLog contacts the selected AI provider to verify your API key and model configuration.
3. **License activation and verification** — TideLog contacts `https://tidelog-api.mydreamchronicle.com` to validate the license key and enforce the 3-device limit. License requests do not include vault note content.
4. **Purchase and license portal links** — Buttons in settings open Afdian or the license portal in your browser. Opening those pages is user-initiated.

TideLog does not include client-side telemetry, analytics SDKs, dynamic ads, or any self-update mechanism. See [PRIVACY.md](./PRIVACY.md) for the full privacy policy.
